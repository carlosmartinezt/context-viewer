HTTP status codes worth remembering

An HTML file with no styles of its own, saved out of a browser and kept because it was useful. It is the shape most HTML files in a notes directory are: content, no design.

The viewer shows it as a browser would, which for a file like this means Times at whatever width the pane happens to be. Turn on Document style in the gear menu to give it a reading width and a familiar face instead. Turn it off and it goes back to being exactly the file.

The ones that come up

CodeNameWhen
204No ContentIt worked and there is nothing to send back
304Not ModifiedThe cached copy is still good
401UnauthorizedWho are you? Log in
403ForbiddenI know who you are, and no
409ConflictSomeone else changed it first
422Unprocessable ContentWell-formed, still wrong
429Too Many RequestsSlow down
502Bad GatewayThe thing behind the proxy is unhappy

The two that get confused

401 is about identity and 403 is about permission. If logging in could fix it, it is a 401. If logging in changes nothing, it is a 403.

A 404 on something that exists is sometimes deliberate: it is how you refuse without admitting the thing is there.

Redirects

  • 301 and 308 are permanent, and browsers cache them hard. Be sure.
  • 302 and 307 are temporary.
  • The 307/308 pair is the one that keeps the method and the body. 301 and 302 let a POST turn into a GET, which is rarely what anyone meant.
