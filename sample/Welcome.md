# Welcome

This is a demo instance of context-viewer, pointed at a folder of sample
notes instead of anything real. Browse the tree on the left, open a file,
right click a row for the rest.

Nothing in this directory is private. Poke around.

## What to try

- **`04_archive/2025/status-page.html`** is an HTML note that brings its own
  stylesheet and uses the viewer's components. It renders here exactly as it
  would if you opened the file in a browser, which is the whole reason a
  document lives in a frame of its own.
- **`03_resources/http-status-codes.html`** is the opposite: an HTML file with
  no design at all. Open it, then turn on **Document style** in the gear menu
  at the bottom of the activity bar. It is off by default, because a file that
  styles itself should be left alone.
- **The gear menu** also holds eleven workbench themes and the minimap toggle.
- **View source** on any file, from the right-click menu or the tab.
- **`CLAUDE.md`** at the root explains how this tree is organised. The folders
  are PARA: inbox, projects, areas, resources, archive.

The agent in the status bar can read and edit these files. It cannot delete or
rename anything: those are buttons in the listing, on purpose.
